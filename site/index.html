Typst Optical Kerning Bench
GitHub Overview Technical review

Reproducible optical kerning evaluation for Typst.

A Rust-first benchmark for testing deterministic, outline-based optical kerning methods against Typst rendering and scripted InDesign Optical baselines.

Open repository Read the overview Read the technical review

What it evaluates

Shaped glyph runs, font metric kerning, outline profiles, ligatures, classic pairs, real words, numbers, and multiple font categories.

Why it exists

Optical kerning is often judged visually. This repo turns that discussion into reproducible renderings, baselines, metrics, and failure cases.

What it is not

It is not an official Typst project, not a ready-to-merge Typst patch, and not a claim that InDesign Optical is mathematical ground truth.

Possible Typst API shape

Typst currently exposes kerning as a boolean. The benchmark does not settle a public API, but it makes one possible direction concrete enough to discuss. 

#set text(kerning: true)  // current metric kerning
#set text(kerning: false) // current disabled kerning

// Possible future shape:
#set text(kerning: "metric")
#set text(kerning: "optical")
#set text(kerning: "none")

Current evidence

The current candidate has gone through 25 evaluation iterations. It uses a metric-prior guarded profile approach: shape first, inspect adjacent glyph clusters, compute small deterministic deltas from outlines, and preserve good font kerning when the evidence does not justify changing it.

  • 31 ligature-capable cases in the current committed suite.
  • 30 no-ligature cases across serif, sans, script, and comic-style/display fonts.
  • Scripted InDesign Optical exports are used as a professional comparison baseline.
  • Typst metric parity is checked before optical differences are treated as evidence.
