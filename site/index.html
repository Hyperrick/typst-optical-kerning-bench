Typst Optical Kerning Bench

Documentation index for a reproducible benchmark around optical kerning in Typst-like constraints. The repository compares deterministic outline-based candidates against Typst metric rendering and scripted InDesign Optical baselines.

This page is intentionally only an entry point. The repository and the Markdown documents are the source of truth.

Typst API sketch

The benchmark does not propose a final API. It uses this sketch only to make the possible behavior concrete. 

#set text(kerning: true)  // current metric kerning
#set text(kerning: false) // current disabled kerning

// Possible future shape:
#set text(kerning: "metric")
#set text(kerning: "optical")
#set text(kerning: "none")
