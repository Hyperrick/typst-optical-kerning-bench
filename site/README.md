# OptiKern Preference Study Site

This directory is generated by `cargo run -p optikern-cli -- survey` and can be published with GitHub Pages. `index.html` contains the five-way A-E preference study, `methods.html` explains the algorithms, and `results.html` reads public aggregate results from the configured endpoint. Samples are embedded as SVG paths, so the hosted page does not need runtime font files. The page stores progress locally in the browser and submits results to the configured endpoint.
